# Проверка Windows

## Статус

Реальная проверка в Блокноте, Chrome/Edge, Telegram Desktop и Word пока **не выполнена**.
В рабочей среде разработки нет доступа к интерактивному сеансу этих приложений Windows.
Положительные автоматические результаты не заменяют этот этап.

| Приложение | Настоящее поле ввода | Статус |
| --- | --- | --- |
| Блокнот Windows 10/11 | Основной редактор | Не проверено |
| Chrome/Edge | `textarea`, `contenteditable`, поле пароля | Не проверено |
| Telegram Desktop | Поле сообщения и форма входа | Не проверено |
| Microsoft Word | Обычный документ, защищённый документ | Не проверено |

После проверки записать версию Windows, версию приложения, выбранный профиль ввода и результат каждого сценария.
Поле, не предоставляющее нужные свойства TSF, должно оставаться без автоправок.

## Сценарии

1. Ввести `Известно что на улице красивый вид `; после паузы проверить единственную вставленную запятую.
2. Повторить с уже правильной запятой. Добавления второго знака быть не должно.
3. Продолжать быстро печатать, нажимать Backspace, переводить строки и вставлять эмодзи.
   Набранные буквы, знаки, выделение и положение курсора должны сохраняться.
4. Во время проверки переключиться на другое поле, окно или документ. Старый ответ не должен менять новый текст.
5. Поставить помощь на паузу, исключить приложение и снять исключение. Проверить следующий реальный набор.
6. После автоправки нажать `Ctrl+Alt+Backspace`. Затем повторить после дополнительного ввода: отмена не должна удалять новый текст.
7. Проверить пароль, PIN, консоль, код и поле только для чтения: автоправки отсутствуют.
8. Скопировать произвольное значение в буфер обмена, выполнить несколько правок и вставить значение в другое поле.
   Содержимое буфера должно остаться прежним.
9. Завершить Java-приложение и продолжить набор. Ввод должен работать обычно, без зависания.
10. Установить приложение, выбрать профиль, включить и выключить автозапуск; удалить приложение.
    Запись автозапуска и регистрация собственного профиля должны удалиться, другие раскладки — сохраниться.

## Потребление ресурсов

Замеры на реальном Windows-сеансе **пока не выполнены**.
После запуска прогреть проверку несколькими предложениями, затем записать рабочий набор памяти и процессорное время
Java-процесса за 60 секунд простоя и 60 секунд обычного набора. Для приложения, содержащего TSF-модуль, сравнить
набор с обычным русским профилем и профилем «Автозапятые».

В отчёте разделять загрузку Java, первую и последующие проверки, простой и активный набор.
Нельзя приписывать замеры контейнера или одной языковой проверки целому приложению Windows.
